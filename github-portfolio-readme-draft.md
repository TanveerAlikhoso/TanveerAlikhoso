## How I build

1. **Audit before ship.** No tool goes live untested — embed file *and* on-page demo, checked separately.
2. **Mobile first, for real.** Phone, tablet, and iOS — not desktop-only and hope. A tool that fails on a 375px phone doesn't ship.
3. **Grounded, or it says "I don't know."** Unanswered questions go to a Gap list. That's a feature, not a bug.
4. **One widget, done right.** New ideas merge into the existing system — never a pile of duplicate widgets.

## What I won't claim

- No rich-snippet promises (Google removed FAQ rich results in May 2026)
- No invented limits, support tiers, or offices
- No sample data dressed up as real customers

If a demo uses sample data, it wears a SAMPLE DATA badge.
